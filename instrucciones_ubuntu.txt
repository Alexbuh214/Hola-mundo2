INSTRUCCIONES PARA UBUNTU - ODOO + DJANGO
========================================

1. INSTALAR DEPENDENCIAS BASICAS
--------------------------------
sudo apt update
sudo apt install -y docker.io docker-compose-plugin git python3 python3-pip python3-venv curl

2. AGREGAR TU USUARIO AL GRUPO DOCKER
------------------------------------
sudo usermod -aG docker $USER
newgrp docker

3. VERIFICAR DOCKER
-------------------
docker --version
docker compose version

4. CLONAR O ABRIR EL PROYECTO
-----------------------------
cd ~
git clone <URL_DEL_REPOSITORIO>
cd UTEProgIIFinal-main

5. LEVANTAR ODOO
----------------
cd odoo
docker compose up -d

6. ACCEDER A ODOO
-----------------
Abrir en el navegador:
http://localhost:8069

Base de datos para crear:
- Master Password: ute2026
- Database Name: progii
- Email: admin
- Password: admin
- Demo data: desmarcado

7. INSTALAR EL MODULO ODOO
--------------------------
cd /home/tu-usuario/UTEProgIIFinal-main/odoo
docker compose exec odoo odoo -d progii -i ute_academico --stop-after-init
docker compose restart odoo

8. LEVANTAR DJANGO
-----------------
cd /home/tu-usuario/UTEProgIIFinal-main/django
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

9. CONFIGURAR LA BASE DE DATOS DE DJANGO
----------------------------------------
Si usas Docker para PostgreSQL:
cd /home/tu-usuario/UTEProgIIFinal-main/django
docker compose up -d

Verificar que PostgreSQL este corriendo en localhost:5433

10. APLICAR MIGRACIONES DE DJANGO
--------------------------------
cd /home/tu-usuario/UTEProgIIFinal-main/django
source .venv/bin/activate
python manage.py makemigrations academico
python manage.py migrate
python manage.py loaddata academico/fixtures/initial_data.json

11. CREAR SUPERUSUARIO DJANGO
----------------------------
python manage.py createsuperuser

12. LEVANTAR EL SERVIDOR DJANGO
-------------------------------
python manage.py runserver 0.0.0.0:8000

13. ACCEDER A DJANGO
--------------------
Abrir en el navegador:
http://localhost:8000/estudiantes/

API DRF:
http://localhost:8000/api/carreras/
http://localhost:8000/api/estudiantes/
http://localhost:8000/api/matriculas/

14. COMANDOS UTILES
------------------
# Odoo
cd /home/tu-usuario/UTEProgIIFinal-main/odoo
docker compose down

docker compose logs -f odoo

# Django
cd /home/tu-usuario/UTEProgIIFinal-main/django
source .venv/bin/activate
python manage.py runserver 0.0.0.0:8000

15. NOTA IMPORTANTE
-------------------
Si cambias modelos o archivos .py en Odoo, debes actualizar el modulo:
cd /home/tu-usuario/UTEProgIIFinal-main/odoo
docker compose exec odoo odoo -d progii -u ute_academico --stop-after-init
